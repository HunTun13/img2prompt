What goes in, and what comes out

A clear image and a chosen model format are enough to start. The resulting fields are separate so you can keep the useful visual evidence and remove guesses.

File or image URL

Use JPG, PNG or WebP up to 10 MB, or paste a public image URL. Private drives and pages requiring a login cannot be fetched.

Model format

Midjourney favors concise image direction and parameters; Flux and DALL·E favor more natural prose; Stable Diffusion may use a focused negative prompt.

Detail control

Short is useful for quick iteration. Detailed captures more visible texture and composition, but still needs a human check before production use.

Main prompt
The image's subject, setting and defining visual decisions in editable language.
Model prompt
A version phrased for the selected image or video generator.
Negative prompt
Specific unwanted artifacts where the target workflow uses exclusions.
Style keywords
Short style and medium cues that you can keep, change or remove.
Lighting and camera
Directions for illumination, framing, lens feel and composition.
Color palette
The major tones that tie the reference together.

Questions before you generate

Can the generator recover the original prompt?

No. A finished image does not reveal its exact words, seed or hidden settings. The tool writes a reusable prompt from visible evidence.

Why are the main and model prompts different?

The main prompt describes the scene in plain language. The model prompt adapts that description to the selected tool's typical syntax or writing style.

Does every model use a negative prompt?

No. Stable Diffusion commonly supports one. For other models, the negative field is guidance to adapt or ignore rather than a universal command.

What happens to my image?

It is sent to the configured AI provider for this request. Img2Prompt does not intentionally retain uploaded image content after processing; see our privacy policy.
